# Vision

This app is a manga-inspired chat experience. It should feel like messages are part of a living comic or manga world, not just text inside generic rectangles.

The goal is not only to build a working chat app. The goal is to make the app feel expressive, character-driven, and visually alive.

## Core Idea

The app should have personality in both text and UI.

A user should feel like they are entering a stylized manga communication space, where chatrooms can have their own tone, world, and expressive behavior.

The design should feel fun and human-made while still being readable and practical.

## Text Personality

The app should not always use plain literal wording like:

- send
- message
- chat
- room

Depending on the room, character, or manga world, the app may use more expressive action words such as:

- shout
- mutter
- whisper
- exclaim
- shoot
- announce
- scribble
- deliver
- burst
- echo

These words should not be random decoration. They should support the tone of the room, character, or world.

For example:

- A dramatic battle-themed room might use `shout` or `burst`.
- A quiet mystery-themed room might use `mutter` or `whisper`.
- A playful room might use `scribble` or `toss`.

## UI Personality

The UI should avoid looking like a generic SaaS chat dashboard.

Avoid:

- Plain stacked rectangular chat cards
- Overly sterile rounded capsules
- Generic sidebar-and-chat layouts without visual personality
- Flat UI with no sense of manga influence
- Decoration that does not support the experience

Prefer:

- Manga panel-inspired layouts
- Irregular chat bubbles
- Human-drawn-feeling shapes
- Slightly imperfect borders
- Expressive dividers
- Playful but readable typography
- Speech-bubble energy
- Thought-bubble variation
- Wavy or dynamic patterns when appropriate
- Asymmetry that still feels intentional

The UI can have flair, motion, dramatic emphasis, and visual personality, but usability comes first.

## Personality Does Not Mean Chaos

The design can be random-feeling, but it should not be truly random in a way that breaks consistency.

Good randomness:

- Slight variation in bubble shape
- Playful spacing
- Different panel framing styles
- Room-specific accent details
- Character-driven verbs and microcopy

Bad randomness:

- Inconsistent navigation
- Hard-to-read text
- Unclear buttons
- Layouts that move unpredictably
- Visual noise that makes chatting harder

## Concept Art Role

Concept art should guide the final UI.

Once concept art is generated and curated, implementation should follow the chosen visual direction instead of inventing a completely new style.

The app-building agent should read `docs/CONCEPT_ART_NOTES.md` before implementing major UI surfaces.
